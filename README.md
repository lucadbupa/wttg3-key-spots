# WTTG3 Key Spot Overlay Screenshots

Rendered screenshots of every keyable page in *Welcome to the Game III* with red overlays showing the exact spots where a key can appear.

## What each overlay means

- **Solid red box** — a click-actionable candidate the player can interact with in the browser widget. This is either a `<a class="CPTAG/CFTAG">` anchor wrapping visible text/image content, or an empty CP/CF-TAG anchor whose CSS positions it as a transparent hotspot overlaid on an image
- **Orange dashed box** — a condition based box where you must interact with something for it to be clickable
